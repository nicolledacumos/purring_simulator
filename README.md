# Purring Simulator

For this lab, I got inspiration from the video we viewed in class about haptic motors that mimicked a cat walking. I created a purring simulator that has different speeds: low vibrations when a user's hand is near, a steady vibration when a user is slowly moving their finger back and forth on the sensor, and a high vibration when a user "scratches" the sensor like they would scratch a cat. 

I used my capacitive touch sensor from the previous lab, including the calibration code to gauge what thresholds I would need to establish for proximity and touch. I found that the sensor slightly changed the ranges pretty drastically, and having items like my phone near the sensor also affected the values. I kept the calibration code in the background while running my purring simulator to actively make changes.

For the setup, I used a photo of my cat, Mazzy, copper tape, and the haptic vibration motor provided in class. I also used AI to help with setting the project up!
